# aT 한국농수산식품유통공사 Brand System
**Version 0.9 — Working Brand System / 2026-08-11**

> 이 문서는 한국농수산식품유통공사(aT)의 공식 웹사이트, 공식 CI 설명, 중장기 경영전략, 설립목적·주요사업과 제공된 로고/사옥 이미지를 바탕으로 정리한 **실무용 브랜드 시스템 초안**입니다.  
> 공식 CI 원본의 색상값·최소사용규정·보호공간·시그니처 조합 등 세부 규정이 별도 매뉴얼에 존재할 경우, 해당 공식 규정을 최우선으로 적용합니다.

## 1. Brand Core

### 1.1 Brand Name
- 국문: **한국농수산식품유통공사**
- 영문: **Korea Agro-Fisheries & Food Trade Corporation**
- 브랜드 약칭: **aT**

### 1.2 Organization Definition
한국농수산식품유통공사(aT)는 농수산식품산업 진흥을 통해 국민의 안정적인 먹거리 확보와 삶의 질 향상에 기여하고, 생산·유통 혁신을 통해 농어촌·농어민의 성장과 대한민국 농수산식품 산업의 경쟁력을 높이는 공공기관이다.

### 1.3 Mission
**농수산식품산업 진흥을 통해 국민의 안정적인 먹거리 확보와 삶의 질 향상에 기여**

### 1.4 Vision
**농어촌·농어민 성장을 위한 생산·유통 혁신으로 농수산식품 강국 실현**

### 1.5 Core Values
1. **책임감** — 국민 먹거리와 공공의 가치를 책임진다.
2. **혁신** — 생산·유통·수출·산업의 변화를 선도한다.
3. **지속가능** — 농어업, 환경, 지역과 함께 오래 성장한다.
4. **전문성** — 데이터와 현장 전문성을 바탕으로 실행한다.

### 1.6 Brand Purpose
**농어업과 시장, 대한민국과 세계를 연결해 더 나은 먹거리 생태계를 만든다.**

### 1.7 Brand Promise
**생산자에게는 성장의 기회를, 산업에는 혁신의 기반을, 국민에게는 안정적인 먹거리를 제공한다.**

## 2. Brand Positioning

### 2.1 Positioning Statement
aT는 농수산식품의 **수급 안정, 유통 혁신, 수출 진흥, 식품산업 육성**을 연결하는 대한민국 농수산식품산업 진흥 전문기관이다.  
정책과 현장, 생산자와 소비자, 국내시장과 글로벌시장을 이어 **공공성과 산업 경쟁력**을 동시에 실현한다.

### 2.2 Brand Territory
브랜드가 지속적으로 소유해야 할 핵심 영역은 다음과 같다.

- **Stable Food** — 안정적인 먹거리와 수급
- **Smart Distribution** — 효율적이고 디지털화된 유통
- **Global K-Food** — 한국 농수산식품의 세계시장 확장
- **Industry Growth** — 식품·외식 산업의 혁신성장
- **Public Trust** — 투명하고 책임 있는 공공기관
- **Sustainable Future** — 농어업과 환경의 지속가능성

### 2.3 Differentiation
aT의 차별점은 하나의 기능에 국한되지 않고 **생산–유통–소비–수출–산업육성의 가치사슬을 연결하는 공공 플랫폼 역할**에 있다.

## 3. Brand Architecture

### 3.1 Master Brand
**aT / 한국농수산식품유통공사**

모든 핵심 정책, 사업, 플랫폼, 캠페인은 aT라는 마스터 브랜드의 신뢰를 기반으로 운영한다.

### 3.2 Brand Architecture Principle
권장 구조는 **Branded House**를 기본으로 한다.

- 기관 브랜드: aT
- 사업 브랜드: aT + 사업명
- 서비스/플랫폼: 고유 서비스명이 필요한 경우에도 aT 보증체계를 명확히 표시
- 글로벌 커뮤니케이션: aT + K-Food 관련 메시지의 일관성 강화

### 3.3 Naming Principle
신규 사업·서비스 이름은 다음 원칙을 권장한다.

- 짧고 이해하기 쉬울 것
- 농수산식품 산업의 기능과 혜택이 드러날 것
- 공공기관다운 신뢰성을 유지할 것
- 지나치게 유행성 있는 표현은 피할 것
- 디지털 서비스는 검색성과 발음 용이성을 고려할 것

## 4. Primary Audiences

### 4.1 Producers
농어업인, 산지조직, 생산자단체

**Need:** 안정적 판로, 소득 증대, 수급·유통 지원  
**Message:** “생산의 가치를 더 큰 시장으로 연결합니다.”

### 4.2 Food & Distribution Industry
식품기업, 유통기업, 외식기업, 푸드테크 기업

**Need:** 성장 기반, 데이터, 정책지원, 판로  
**Message:** “산업의 혁신과 성장을 함께 설계합니다.”

### 4.3 Exporters & Global Buyers
수출기업, 해외 바이어, 유통 파트너

**Need:** 시장정보, 수출지원, 거래 연결, K-Food 신뢰  
**Message:** “K-Food의 가능성을 세계시장과 연결합니다.”

### 4.4 Citizens & Consumers
국민, 소비자, 공공급식 이용자

**Need:** 안정적인 먹거리, 투명한 정보, 합리적인 소비  
**Message:** “국민의 일상에 안정적이고 신뢰할 수 있는 먹거리를 더합니다.”

### 4.5 Government & Public Partners
정부, 지자체, 공공기관, 연구·교육기관

**Need:** 정책 실행력, 데이터, 협업, 공공성과  
**Message:** “정책과 현장을 연결해 실질적인 변화를 만듭니다.”

## 5. Brand Personality

aT의 브랜드 성격은 다음 5개 키워드로 정의한다.

### Trusted
정확하고 투명하며 책임감 있다.

### Expert
현장과 데이터를 이해하는 전문기관이다.

### Connected
생산자, 시장, 국민, 세계를 연결한다.

### Progressive
디지털 전환과 산업 혁신을 선도한다.

### Sustainable
사람과 산업, 환경의 지속가능한 성장을 지향한다.

### Personality Balance
- 공공적이되 **관료적이지 않게**
- 전문적이되 **어렵지 않게**
- 혁신적이되 **가볍지 않게**
- 친근하되 **신뢰를 잃지 않게**
- 글로벌하되 **한국 농수산식품의 정체성을 유지하게**

## 6. Verbal Identity

### 6.1 Voice
aT의 기본 목소리는 **신뢰할 수 있는 산업 전문가이자 현장 파트너**다.

### 6.2 Tone by Context

| 상황 | 톤 |
|---|---|
| 정책·공공정보 | 정확함, 투명함, 중립성 |
| 농어업인 대상 | 실용적, 명확함, 현장 중심 |
| 기업 지원 | 전문적, 적극적, 성장 지향 |
| 국민 캠페인 | 친근함, 쉬운 언어, 생활 밀착 |
| 글로벌 홍보 | 자신감, 명료함, 국제적 감각 |
| 위기·이슈 | 신속함, 사실 중심, 책임 있는 표현 |

### 6.3 Writing Principles
- 결론을 먼저 제시한다.
- 한 문장에는 하나의 메시지를 담는다.
- 행정용어는 가능한 한 일상어로 바꾼다.
- 숫자와 기준은 출처와 기준시점을 명확히 한다.
- 정책의 설명보다 **이용자에게 생기는 혜택**을 먼저 말한다.
- “지원합니다”에 그치지 않고 무엇을 어떻게 지원하는지 구체적으로 쓴다.

### 6.4 Preferred Vocabulary
**권장**
- 연결
- 성장
- 안정
- 혁신
- 신뢰
- 현장
- 데이터
- 글로벌
- 지속가능
- 함께

**지양**
- 추상적인 관용적 표현의 반복
- 과도한 행정문서식 명사 나열
- 근거 없는 최상급 표현
- 국민·고객이 이해하기 어려운 내부 약어

### 6.5 Message Formula
**대상 + 변화 + aT의 역할 + 공공적 가치**

예:
> 농어업인의 좋은 상품이 더 넓은 시장을 만날 수 있도록, aT가 유통과 수출의 길을 연결합니다.

## 8. Visual Identity

## 8.1 Logo Concept
공식 CI 설명에 따르면 aT 워드마크는 소문자 **a**와 대문자 **T**의 결합으로 구성된다.

- **a**: 싹이 움트고 성장하는 이미지 → 농식품산업의 발전성과 생산성
- **숟가락 형상**: 대한민국 먹거리를 책임지는 공사의 역할
- **T**: 타워 이미지 → 신뢰받는 농수산식품산업 전문 공기업의 지향점

### 8.2 Logo Usage Principle
- 공식 제공 로고 원본만 사용한다.
- 가로·세로 비율을 임의로 변형하지 않는다.
- 구성요소를 임의로 분리·재조합하지 않는다.
- 자간·형태·기울기 등을 임의로 수정하지 않는다.
- 복잡한 사진 위에서는 충분한 대비와 여백을 확보한다.
- 공식 CI 매뉴얼의 보호공간, 최소크기, 색상규정이 있을 경우 이를 우선 적용한다.

### 8.3 Working Digital Color Palette
> 아래 값은 제공된 로고 이미지의 색상 인상을 기준으로 만든 **디지털 작업용 제안 팔레트**이며, 공식 CI 원본의 지정색 값과 다를 수 있다. 최종 제작물은 공식 CI 색상값 확인 후 확정한다.

| Role | Name | HEX | Use |
|---|---|---|---|
| Primary | aT Deep Teal | `#09524D` | 로고 연계, 헤드라인, 핵심 UI |
| Primary 2 | Growth Green | `#488835` | 성장, 농업, 강조 영역 |
| Secondary | Field Green | `#97AF79` | 보조 그래픽, 인포그래픽 |
| Light | Fresh Mist | `#CDDEC8` | 배경, 카드, 정보 구분 |
| Neutral | Charcoal | `#2B2F2F` | 본문 텍스트 |
| Neutral | White | `#FFFFFF` | 여백, 배경 |
| Optional Accent | Harvest Red | `#C83A32` | 식품·성과·CTA의 제한적 강조 |

### 8.4 Color Ratio
기본 디지털 화면 권장 비율:
- White / Light Neutral: **60–70%**
- Deep Teal: **15–20%**
- Growth Green: **10–15%**
- Secondary/Accent: **5% 이하**

### 8.5 Accessibility
- 본문 텍스트와 배경은 WCAG 기준의 충분한 명도 대비를 확보한다.
- 색상만으로 상태나 정보를 구분하지 않는다.
- 빨강/초록만의 대비에 의존하지 않는다.
- 중요 버튼은 색상 + 텍스트 + 형태를 함께 사용한다.

## 11. Graphic Language

### 11.1 Core Motif: “Flow”
aT의 기능을 하나로 연결하는 시각 개념은 **흐름(Flow)**이다.

표현 대상:
- 생산 → 유통 → 소비
- 지역 → 전국 → 세계
- 데이터 → 정책 → 현장
- 농어업 → 식품산업 → 국민

### 11.2 Graphic Forms
- 연결선
- 성장 곡선
- 유통 네트워크
- 필드/논밭을 연상시키는 그리드
- 원형 또는 노드 구조
- 씨앗→성장→확장의 단계형 패턴

### 11.3 Iconography
- 선형 또는 단순 면형 아이콘
- 동일한 스트로크와 라운딩 규칙
- 장식보다 정보 전달 우선
- 농업, 수산, 물류, 수출, 데이터 등 사업영역을 통일된 스타일로 표현

## 12. Layout System

### 12.1 Principles
- **Public Clarity**: 누구나 빠르게 이해할 수 있어야 한다.
- **Structured Information**: 복잡한 정책정보를 계층적으로 정리한다.
- **Open Space**: 충분한 여백으로 신뢰감과 현대성을 만든다.
- **Data First**: 수치와 성과는 시각적으로 빠르게 읽히게 한다.

### 12.2 Recommended Grid
- Digital: 12-column responsive grid
- Presentation: 12-column grid
- A4 document: 6-column modular grid
- Mobile: 4-column grid

### 12.3 Shape Language
- 기본: 직선, 단정한 사각형
- 보조: 부드러운 라운드
- 자연·성장 메시지: 유기적 곡선 제한적 사용

## 13. Data Visualization

aT는 정책·시장·가격·수출·유통 데이터를 다루는 기관이므로 데이터 시각화도 브랜드의 핵심 접점으로 관리한다.

### Principles
- 결론이 먼저 보이게 한다.
- 하나의 차트에 메시지를 하나만 둔다.
- 범례보다 직접 라벨을 우선한다.
- 3D 차트는 사용하지 않는다.
- 핵심 수치는 Deep Teal 또는 Growth Green으로 강조한다.
- 비교 기준, 기간, 단위, 출처를 항상 표시한다.
- 상승·하락의 의미가 상황마다 다르므로 단순히 초록=좋음, 빨강=나쁨으로 고정하지 않는다.

## 14. Digital UI Principles

### 14.1 UX Keywords
**Clear / Trusted / Fast / Inclusive**

### 14.2 Components
- Primary Button: Deep Teal 기반
- Secondary Button: White + Teal Border
- Success/Positive: Green 계열
- Warning/Error: 별도 접근성 검증 색상 사용
- Cards: White 배경 + 명확한 정보 계층
- Data Modules: 큰 수치 + 짧은 설명 + 기준일

### 14.3 Public-service UX
- 첫 화면에서 “사업 설명”보다 **사용자가 할 수 있는 행동**을 명확히 제시
- 신청 자격, 기간, 제출자료를 한 화면에서 확인 가능하게 구성
- 모바일 환경을 우선 고려
- 고령층과 디지털 취약계층을 고려해 쉬운 언어와 충분한 클릭 영역 사용

## 16. Brand Do / Don’t

### Do
- 공공기관의 신뢰와 전문성을 최우선으로 한다.
- 농어업인과 국민의 관점에서 설명한다.
- 데이터와 출처를 명확히 제시한다.
- 사업 간 시각적·언어적 일관성을 유지한다.
- 디지털·글로벌 환경에서도 aT 마스터 브랜드를 명확히 한다.
- 현장성과 사람을 보여준다.

### Don’t
- 로고를 임의 변형하지 않는다.
- 사업마다 전혀 다른 스타일을 만들지 않는다.
- 과도한 그라디언트, 장식, 유행 디자인으로 공공 신뢰감을 약화시키지 않는다.
- 지나치게 어려운 행정용어를 첫 메시지에 사용하지 않는다.
- 성과를 근거 없는 최상급 표현으로 과장하지 않는다.
- 농업 이미지를 전통적·낙후된 모습으로만 표현하지 않는다.
